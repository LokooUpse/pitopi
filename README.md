# SoundBridge P2P — Веб-сервис передачи системного звука с ПК на телефон

Веб-сервис для трансляции звука со всего компьютера («Хост») на один или несколько смартфонов («Пользователь») в реальном времени через **WebRTC (Opus Stereo до 320 kbps)**.

## Почему сервис идеально работает на бесплатном веб-хостинге
1. **Прямой P2P-поток (WebRTC)**: Сам звук передается **напрямую между ПК и телефоном** (по вашему домашнему Wi-Fi / локальной сети с задержкой `< 15 мс`), не нагружая веб-хостинг и не требуя платных медиасерверов.
2. **Поддержка 100% бесплатных статических хостингов (без бэкенда)**:
   - По умолчанию используется бесплатный облачный сигналинг **PeerJS Cloud** + публичные STUN-серверы Google и Cloudflare.
   - Также встроен **бессерверный режим (Ручной обмен SDP)**, который работает даже без доступа к внешним сигнальным серверам.
   - В папке `server/` также приложен опциональный сервер на Node.js (`Express + PeerServer`), если вы захотите развернуть сервис на Render.com, Railway или запустить локально.

## Быстрый деплой на бесплатный хостинг (за 1 минуту)

> **Важно:** Браузеры разрешают захват системного звука (`getDisplayMedia`) только на страницах с **HTTPS** (или на `http://localhost`). Любой бесплатный хостинг ниже выдает бесплатный HTTPS-сертификат автоматически.

### Способ 1: Netlify Drop (без регистрации Git-репозитория, за 30 секунд)
1. Перейдите на [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите распакованную папку `soundbridge_service` в окно браузера.
3. Вы мгновенно получите бесплатную HTTPS-ссылку вида `https://your-site.netlify.app`.

### Способ 2: GitHub Pages / Vercel / Cloudflare Pages
1. Создайте бесплатный репозиторий на GitHub и загрузите туда содержимое архива.
2. В настройках репозитория откройте **Settings → Pages** и выберите ветку `main`.
3. Через минуту ваш сервис будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

### Способ 3: Запуск на бесплатном Node.js хостинге (Render.com) или локально
```bash
npm install
npm start
# Сервис откроется на http://localhost:9000
```

## Как пользоваться сервисом

### Шаг 1. На компьютере (Хост)
1. Откройте ссылку на сервис в браузере на базе Chromium (**Google Chrome, Microsoft Edge, Brave, Opera, Яндекс.Браузер**).
2. Во вкладке **«Хост (ПК)»** выберите источник **«Весь системный звук ПК»** и нажмите **«Запустить трансляцию звука с ПК»**.
3. В появившемся системном окне браузера:
   - Перейдите на вкладку **«Весь экран» (Entire Screen)**.
   - Обязательно поставьте галочку внизу: **«Поделиться системным звуком» (Also share system audio)**.
   - Нажмите **«Поделиться»**. *(Сервис автоматически отключит видеодорожку, чтобы не расходовать трафик и процессор, и оставит только стереозвук 48 кГц).*

### Шаг 2. На телефоне (Пользователь)
1. Отсканируйте **QR-код** с экрана компьютера камерой телефона (или откройте ссылку сервиса на телефоне, перейдите во вкладку **«Телефон (Клиент)»** и введите 6-значный код комнаты).
2. Нажмите **«Подключиться»**, а затем большую кнопку **«Включить воспроизведение звука»** (необходимо для снятия блокировки автовоспроизведения на iOS/Android).
3. Используйте встроенный **буст громкости (до 200%)**, **3-полосный эквалайзер** и переключатель **WakeLock** (чтобы телефон не уходил в сон).
