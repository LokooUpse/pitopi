Как развернуть на бесплатном веб-хостинге и передавать весь звук с ПК

Вариант 1: GitHub Pages / Netlify / Vercel

Сервис работает полностью на статическом бесплатном хостинге! Просто распакуйте архив и загрузите файлы (index.html, css/, js/) на GitHub Pages, Netlify Drop (app.netlify.com/drop) или Cloudflare Pages. HTTPS включится автоматически, а WebRTC соединит ПК и телефон напрямую по локальной сети с задержкой менее 15 мс.

Вариант 2: Как захватить весь звук Windows/macOS

1. Откройте сервис на ПК в Chrome, Edge, Brave или Яндекс.Браузере.
2. Нажмите «Запустить трансляцию звука с ПК».
3. В появившемся окне выберите вкладку «Весь экран» (Entire Screen) и внизу обязательно поставьте галочку «Поделиться системным звуком» (Also share system audio).
4. Видеопоток автоматически отключается программой — передается только чистый стереозвук!

Вариант 3: Стерео микшер / VB-Audio Cable

Если вы хотите захватывать звук через список микрофонов/устройств без диалога выбора экрана, включите в звуковых настройках Windows «Стерео микшер» (Stereo Mix) или установите бесплатный драйвер VB-CABLE, после чего выберите карточку «Стерео микшер / VB-Cable» на вкладке Хоста.
